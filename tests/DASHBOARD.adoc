== Partial-recovery extension (2026-11-07)

The optional Epistemic comparison now imports the actual partial-recovery
interface from `epistemic-types` commit
`6ce8c74e8a91e5021cb0c1fb4fc805bdff837178`. It adds fibre/candidate
translations, source-separation and identification implications, and a
decoder construction requiring an explicit image decision. Positive
examples include a locally identified fibre in a retention that provably
admits no global partial decoder. The sibling rejection inventory is now
8 controls, each with an independently checked prefix. Local validation at
implementation commit `686cafe2cba06666df4e4c0539fa43a69794447f` accepted both
comparisons and all eight prefixes, rejected the eight invalid declarations,
and passed the core, K9 configuration and explorer gates. These changes need
their own hosted receipt; the historical results below cover only their
cited trees.

== Performance benchmark status

There is no dedicated performance benchmark harness or measured baseline
for latency, throughput or memory use in this repository. The counts above
describe correctness checks and their finite scope. GitHub Actions elapsed
time and the historical proof-run timings are not reproducible performance
benchmarks, so no speed, resource-efficiency or regression threshold is
claimed here.

A future benchmark would need a specified workload, toolchain and hardware,
an explicit cache policy, repeated measurements and retained raw results
before this section could report performance comparisons.

== Running the recorded checks

[source,bash]
----
just check
just check-siblings
just correspondence
----

`just check-all` combines the first two commands; correspondence remains a
separate command. Without Just, invoke `bash scripts/check.sh`,
`bash scripts/check-siblings.sh` and `bash scripts/correspondence.sh`.
The sibling gate needs Git access to the pinned source revisions;
correspondence needs bun. Logs are written beneath ignored `_build/`.

Update this dashboard when the verified scope changes, using an actual
successful run and its exact revision. Keep older receipts as history and
report missing measurements as missing measurements.
